# Dataset
The GitHub-safe datasets in this folder are derived from the supplied Excel workbook.

- `Raw_Data/Patient_Raw_Data_Anonymized.csv` — source patient records with direct personal/contact fields removed.
- `Cleaned_Data/Patient_Cleaned_Data.csv` — cleaned dataset used for analysis, including the `Age Group` field.
- `Filtered_Data/Patient_Filtered_Pune_Example.csv` — example filtered extract where `City = Pune`, for demonstrating Power BI filtering.

The original workbook is intentionally not copied into this public-ready package because it contains fields such as names, phone numbers, email addresses, addresses and insurance policy numbers.
